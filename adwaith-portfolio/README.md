# Adwaith Ajay Portfolio

## Run locally

1. Open this folder in Antigravity.
2. Open the terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost URL shown by Vite.

## Before using Contact

Edit:

`src/config/profile.js`

and replace `YOUR_EMAIL@gmail.com` with your real email address.
